### 踩过的坑（3 个关键修复）
1. **CUPTI 版本冲突**：sol-execbench 默认拉 cupti-python 13.x（要 libcupti.so.13），与 torch cu121 栈冲突 → `pip install cupti-python==12.8.0`
2. **AKA 真 bug（已 patch）**：`tools/sandbox.py` 的沙箱上传 allowlist `EVALUATION_INPUT_PATHS` **漏了 `config.json`** → 沙箱内 sol-execbench 不跑 reference 基准 → speedup=0 → V0 误判失败。一行修复：allowlist 加 `"config.json"`。这个可以给上游提 PR。
3. **SOL definition schema**：需要 `axes`（const/var）+ 字符串 axis 名的 shape + 内嵌 reference 代码字符串（返回值风格）+ workload 带 uuid/tolerance——与直觉的裸 PyTorch 布局不同，试了 3 轮才对。
